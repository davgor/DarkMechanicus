## Verification — 2026-09-30

`npm run build` emits `out/main/mcp.js` (electron-builder packs `out/**/*`); `src/main/desktop/mcpConfig.test.ts` covers the packaged snippet (`ELECTRON_RUN_AS_NODE=1`); `npm run smoke:mcp` passes under Node and Electron; runbook `docs/runbooks/mcp-setup.md`.

Packaged check: `electron-builder --linux dir` puts `out/main/mcp.js` (and its chunk) in `resources/app.asar`. With `MCP_SMOKE_COMMAND=<packaged executable>` and `MCP_SMOKE_SERVER=<resources>/app.asar/out/main/mcp.js`, the smoke script passes against the packaged build: 50 tools, 6 prompts, one ticket accepted. The packaged window also launches under Xvfb (`app.isPackaged` true), initializes a Git folder, and creates an epic. Windows and macOS installers are still unverified (014.3).
