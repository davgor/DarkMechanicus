Packaging note: packed from this worktree, whose `node_modules` is a junction to a shared install, electron-builder
left the hoisted dependencies out of `app.asar` (52.6 MB instead of 60.2 MB; `express`, `ajv`, `d3-*` and more missing),
and that executable stopped at startup in the main process (no window, no DevTools endpoint). The package above was built
from `git archive` of the same commit with a real copy of that `node_modules`; the installed app is built the normal
way and is unaffected. Package from a real `node_modules`, never through a junction.
