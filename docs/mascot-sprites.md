# Mascot action sprite atlases

Six transparent raster atlases for the chibi tech priest mascot are in `src/renderer/src/assets/mascot/`. Playback contract and explicit row-major frame rectangles are in [`atlas.json`](../src/renderer/src/assets/mascot/atlas.json). Every sheet is 1536×1024 px: three columns by two rows of 512×512 px cells. Frames share the same cell origin; transparent padding is part of each cell. Each frame has its own local `footAnchor` measured from the alpha-visible contact extent to avoid baseline jumps. The action-level `footAnchor` is the fallback. Apply each action `renderScale` to the nominal cell display size and to both coordinates of the source-local frame anchor; frame rectangles remain unchanged. `jump` and `climb` use `renderScale: 0.78` to normalize their larger generated character drawings against the other four actions (`1.0`). For jump playback, the runtime supplies vertical trajectory movement while pinning the scaled frame-local anchor. Walk and run face right and may be mirrored for left-facing playback. Idle, walk, run, and climb loop; jump and stumble play once.

## Assets and provenance

The built-in ImageGen tool generated all six assets from `build/mechanicus-cute-master.png` as the visual identity reference. ImageGen outputs were copied from the local generated-images directory into the project; no Python processing, hand-painted frame edits, or vector stand-ins were used. The last framing edits preserve each action's generated poses while adding transparent margin.

- `idle.png` — ImageGen output `exec-6a32cdcc-fe7b-40a5-835d-37f2feb2f2e4.png`, framing edit of `exec-c3b35638-1b47-4309-b0e3-a25eb042b04e.png`. Prompt: “Preserve the six idle fidget poses and all character details, identity, pose differences, 3×2 grid, colors and canvas. In every 512×512 cell uniformly shrink the complete pose to about 78%, center it, and leave at least 28 transparent pixels on all four sides, especially above hood and under boots. Keep 1536×1024 canvas. Do not crop, redraw, duplicate, rotate, flip, or change gestures. Preserve genuine transparent alpha outside the character.” The original pose prompt requested six sequential idle fidgets: settled, hood bob, curious tilt, hand twitch, robe sway, return.

## Validation

For a local visual check, run `npx vite --config preview/mascot/vite.config.ts --host 127.0.0.1 --port 5178` from the repository root. Open `http://127.0.0.1:5178/preview/mascot/actions.html` for all six action atlases at board scale and a deterministic side jump, climb, and top walk on a three-ticket board. Open `http://127.0.0.1:5178/preview/mascot/graph.html` for the real single-sprint PlanGraph with pan, zoom, drag, selection, model movement, and the mascot pause control. These development-only pages are separate Vite pages, not app navigation routes or production entries.

The six saved PNGs were inspected in a browser on neutral backgrounds. Each is 1536×1024, RGBA, with six recognizable action poses. Sharp metadata and per-cell alpha-bounds inspection verified that each silhouette stays inside its own 512×512 rect after the framing edits. Transparent background samples have alpha 0 and mascot samples have near-opaque alpha; the red-looking preview in some image viewers is their transparency composite, not painted background. Frame rectangles and both per-frame and fallback action foot anchors are explicit in `atlas.json`. Per-frame local y anchors were measured from the bottommost alpha-visible pixel at alpha >128; x is cell center (256). This keeps grounded contacts aligned across changes in pose.
