# 009.3 — Repository layout, initialization, path containment

`.darkmechanicus/` layout with `project.json`, `.gitignore` (`local/`), `local/machine.json`; explicit, repeatable initialization that never commits; owned paths built from validated ids and verified to stay inside `.darkmechanicus/` (symlinks/junctions included).

## Acceptance criteria

- [ ] Initializing creates the layout and is repeatable without changing an existing project id (tested)
- [ ] `.darkmechanicus/.gitignore` ignores `local/` so the live database never enters Git (tested)
- [ ] Owned path helpers reject malformed ids, traversal, and symlinked escapes with `unsafe_path` (tested)
- [ ] Repository root discovery walks up to `.darkmechanicus/project.json` or `.git` (tested)
