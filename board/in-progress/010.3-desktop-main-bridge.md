# 010.3 — Desktop main process and preload bridge

Machine-local tracked-folder registry with canonical-path dedupe, native folder picker, per-folder desktop Workspace, allow-listed `dm:command` IPC with payload validation, MCP config snippet, clipboard, safe external links, navigation lockdown.

## Acceptance criteria

- [ ] Tracking an already-registered canonical path selects it instead of duplicating; stop tracking removes only the registry entry (tested)
- [ ] IPC rejects unknown commands and untracked folders (tested)
- [ ] External links open only for http/https/mailto; navigation and new windows are denied (tested)
- [ ] Preload exposes a typed `window.dm` with contextIsolation and sandbox unchanged
