# 009.5 — Reconstruction and transactional import

Rebuild the local database from tracked records on first open/clone; detect changed tracked state on pull/branch change; stage and validate the full import before one transactional swap; surface conflicts instead of overwriting unexported local changes.

## Acceptance criteria

- [ ] Copying `.darkmechanicus/` without `local/` to another directory reconstructs epics, revisions, statuses, and run history (tested)
- [ ] An invalid or partial import changes nothing and reports why (tested)
- [ ] Tracked changes to an epic with pending local exports are reported as a conflict and not applied (tested)
- [ ] A changed checkout branch pauses active runs and blocks save/dispatch until reconciled (tested)
