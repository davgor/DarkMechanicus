# 012.3 — Claims, leases, submissions, acceptance, failure

## Acceptance criteria

- [ ] Competing claims for one ticket produce exactly one attempt (tested)
- [ ] Heartbeats extend leases; expired leases require reconciliation before a new claim (tested)
- [ ] Late writes from superseded or expired claims are rejected (tested)
- [ ] Accept completes the ticket; reject/fail allow retries up to the limit; `onTicketFailure` policies apply (tested)
- [ ] Idempotent retries of claim/submit/accept return the original result (tested)
