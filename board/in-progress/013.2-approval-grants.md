# 013.2 — Human approval grants and advancement

## Acceptance criteria

- [ ] Human-gated sprints advance only by consuming a desktop-issued grant bound to run, revision, sprint, and report hash (tested)
- [ ] Forged, replayed, and stale (report changed / revision adopted) grants are rejected (tested)
- [ ] Auto policy advances only when the user authorized auto-continue on that run; agents cannot enable it (tested)
- [ ] Advancing the final sprint completes the run and the epic with its outcome (tested)
