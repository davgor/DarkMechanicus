# 011.4 — Plan graph UI

React Flow vertical flowchart: epic containment at the top (no edges), sprint regions with labels, checkpoint dividers, ticket cards with state label + color, solid (met) vs dashed (waiting) dependency edges; draft editing by connecting handles and moving tickets between sprints with server-validated rejections.

## Acceptance criteria

- [ ] The pure graph model lays out sprints top to bottom with tickets placed below their prerequisites (tested)
- [ ] Edge style reflects whether the prerequisite is accepted (tested)
- [ ] Rejected dependency edits show the server's concrete reason (tested)
- [ ] Ticket states always pair color with a text label
