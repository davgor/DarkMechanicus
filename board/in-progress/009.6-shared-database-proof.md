# 009.6 — Desktop + headless process share one database

Prove the Electron runtime and a separate Node process open and migrate the same repository-local database, and that competing writers never duplicate claims.

## Acceptance criteria

- [ ] `node:sqlite` loads inside Electron's runtime (`ELECTRON_RUN_AS_NODE=1`) and system Node (verified, recorded in 0001)
- [ ] A multi-process stress script races claims on one ticket and observes exactly one winner (`scripts/spike/claim-stress.ts`, run and recorded)
- [ ] Opening a database while another process holds the write lock waits (busy timeout) instead of failing (tested)
