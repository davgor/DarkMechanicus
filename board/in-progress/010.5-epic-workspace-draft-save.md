# 010.5 — Epic workspace with Draft / Save / Discard

Epic header with folder, title, bucket, revision; separate Draft and Saved views with an unsaved-change indicator; Save and Discard; conflicts refresh the draft while keeping unsaved form edits; safe Markdown rendering.

## Acceptance criteria

- [ ] Draft and Saved views are distinct, with visible Save/Discard and a draft badge (tested)
- [ ] A save conflict reloads the draft and keeps the user's unsaved field text (tested)
- [ ] Markdown renders without executing HTML/script and only allow-listed links are clickable (tested)
- [ ] Completed epics open read-only with no reopen action (tested)
