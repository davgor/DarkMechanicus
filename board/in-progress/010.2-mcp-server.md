# 010.2 — Headless stdio MCP server

Independently launched MCP process (`out/main/mcp.js`) with role/save flags, session registration and heartbeat, structured JSON results and errors; discovery, repository lifecycle, authoring, and planning tools.

## Acceptance criteria

- [ ] `node out/main/mcp.js --repo <dir>` serves tools over stdio with the desktop closed (smoke-tested with an MCP client)
- [ ] Tool inputs are validated; errors return `{ ok: false, error: { code, message } }` with `isError` (tested)
- [ ] Roles come from launch flags; a planner without `--allow-save` cannot save (tested)
- [ ] An agent can create an epic, add tickets with dependencies to a draft, validate, and (when allowed) save through MCP (tested end to end)
